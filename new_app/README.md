# מעקב התמחות במשרדי עורכי דין

אפליקציית מעקב אינטראקטיבית בעברית (RTL), מותאמת למחשב ולטלפון, לניהול תהליך ההתמחות במשרדי עורכי דין.

## תכונות עיקריות
- **טבלה אינטראקטיבית + תצוגת כרטיסים לטלפון:** חיפוש מהיר, מיון (ברירת מחדל לפי *"האם רלוונטי לבקר?"* ואז *"התאמה לפרופיל שלי"*), וסינון לפי כל אחד מהשדות הנפתחים (כולל מחלקה שנבנית דינמית).
- **כרטיס משרד ועריכה בזמן אמת:** לחיצה על שורה או כרטיס פותחת חלונית עריכה מלאה עם שמירה אוטומטית וחיווי **"נשמר"**.
- **סטטוס הערות מסיור + הערות מסיור חופשיות:** עמודת *"הערות מסיור בקובץ"* מוצגת כסטטוס (`בוצע` / `טרם`), ובנוסף קיים שדה טקסט חופשי נפרד בשם **"הערות מסיור"**.
- **הוספת משרד וארכיון:** הוספת משרד חדש ידנית, העברה לארכיון (עם שחזור), ומחיקה סופית רק לאחר אישור מפורש.
- **סיכום עליון:** משרדים פעילים, קו״ח הוגשו, נשלח מייל, התקבל עדכון (ענו), וסיורים שבוצעו.
- **שמירת ערכים מותאמים:** ערכים חדשים שיופיעו בעתיד באקסל ואינם ברשימות הנפתחות נשמרים כפי שהם ואינם נמחקים.
- **ייבוא וייצוא לאקסל (XLSX):** ייצוא באותו מבנה עמודות כגיבוי, וייבוא חוזר ללא דריסת שדות שמילאת באתר.

## התקנה והרצה מקומית (localhost:3000)

### 1. התקנת Node.js
יש להתקין **Node.js גרסה 20 ומעלה** מהאתר הרשמי:
https://nodejs.org

לבדיקה שהותקן בהצלחה, פתחו טרמינל והריצו:
```bash
node -v
npm -v
```

### 2. שכפול הפרויקט מ-GitHub
```bash
git clone https://github.com/RoyZu4retz/employer_fair_eden.git
cd employer_fair_eden/new_app
```

### 3. התקנת חבילות
```bash
npm install
```

### 4. הוספת קובץ האקסל וייבוא הנתונים
1. שימו את קובץ האקסל בתיקיית `new_app/data/` בשם `offices.xlsx` (גיליון `"משרדים פרטיים"`).
2. הריצו ייבוא:
```bash
npm run import
```
- הייבוא יוצר/מעדכן את `data/tracker.json`.
- **ייבוא חוזר אינו דורס שדות שכבר מילאת באתר** (הזיהוי מתבצע לפי `"שם המשרד"`).
- תיקיית `data/` מוחרגת ב-`.gitignore` ונשארת מקומית בלבד.

### 5. הפעלת האתר מקומית
```bash
npm run dev
```
פתחו בדפדפן:
**http://localhost:3000**

השרת מאזין אך ורק ל-`localhost` (`127.0.0.1`), מבצע כתיבה אטומטית ובטוחה (קובץ זמני והחלפה) ל-`data/tracker.json`, ושומר אוטומטית עותק גיבוי אחרון ב-`data/tracker.backup.json`.

## גיבוי וייצוא
- לחצו על כפתור **"ייצוא לאקסל"** בסרגל העליון להורדת קובץ `.xlsx` מלא באותו מבנה עמודות (RTL).
- תחת **"גיבוי / ייבוא"** ניתן גם לייצא/לשחזר גיבוי JSON או למזג קובץ אקסל חדש ישירות מהדפדפן.
